# Ch13 Route B: Mathlib-backed route for vertex LP optimality / edge tangent cone

This is the requested Mathlib/Lean route for the final convexity theorem:

> At a vertex `v` of a finite convex polytope, if a linear functional is nonnegative on every outgoing edge direction, then it is nonnegative on every displacement `x - v` from `v` into the polytope.  Equivalently, every vertex displacement lies in the nonnegative cone generated by the outgoing edge directions.

## Search result: what current Mathlib gives directly

### Convex hull / finite convex combinations: YES

Use:

* `convexHull` from `Mathlib.Analysis.Convex.Hull`.
* `convexHull_min` and `mem_convexHull_iff`.
* `Finset.mem_convexHull'`, the most useful finite statement:

```lean
x ∈ convexHull R (s : Set E) ↔
  ∃ w : E → R,
    (∀ y ∈ s, 0 ≤ w y) ∧
    ∑ y ∈ s, w y = 1 ∧
    ∑ y ∈ s, w y • y = x
```

* `Set.Finite.convexHull_eq` for finite sets.
* `mem_convexHull_iff_exists_fintype` / `mem_convexHull_of_exists_fintype` when a finite type of coefficients is more convenient.

For the final “all points of the polytope” step, `Finset.mem_convexHull'` is the cleanest theorem: it turns `x ∈ convexHull` into nonnegative barycentric weights, and the linear-functional inequality is just `Finset.sum_le_sum`.

### Extreme points: YES, but not enough for this theorem

Use:

* `Set.extremePoints` from `Mathlib.Analysis.Convex.Extreme`.
* `mem_extremePoints`, `mem_extremePoints_iff_left`, `mem_extremePoints_iff_forall_segment`.
* `Convex.mem_extremePoints_iff_convex_sdiff` and `Convex.mem_extremePoints_iff_mem_sdiff_convexHull_sdiff`.
* `extremePoints_convexHull_subset`.

These are useful for proving a designated point is a vertex/extreme point, but they do **not** supply the local edge-cone optimality theorem.  In particular, I did not find a Mathlib theorem saying “checking a linear functional on the edges adjacent to an extreme point suffices for global optimality.”

### Convex cones / dual cones / Farkas: PARTIAL YES

Use:

* `ConvexCone` from `Mathlib.Geometry.Convex.Cone.Basic`.
* `ConvexCone.hull`, `ConvexCone.subset_hull`, `ConvexCone.hull_min`, `ConvexCone.hull_le_iff`.
* `ConvexCone.map`, `ConvexCone.mem_map`, `ConvexCone.comap`, `ConvexCone.mem_comap`.
* `ConvexCone.positive`, `ConvexCone.mem_positive`.
* `ProperCone` and the topological dual-cone API from `Mathlib.Analysis.Convex.Cone.Dual`:
  * `ProperCone.dual`
  * `ProperCone.mem_dual`
  * `ProperCone.hyperplane_separation`
  * `ProperCone.hyperplane_separation_point`
  * `ProperCone.dual_flip_dual`
  * `ProperCone.dual_dual_flip`

Important naming note: I did **not** find declarations named `inner_dualCone` or `dualCone_dualCone`.  The current Mathlib API is generic in a perfect bilinear pairing and uses `ProperCone.dual p s`; membership rewrites by `ProperCone.mem_dual`.

### Tangent cone / normal cone / polyhedral H=V: NOT FOUND

I did not find a direct Mathlib API for any of the following under those names:

* `tangentCone`
* `normalCone`
* `Mathlib.Analysis.Convex.Normal`
* a polyhedral cone theorem `H`-representation = `V`-representation
* `ConvexCone.FG`
* `MinkowskiWeyl`
* a vertex/simplex LP optimality theorem for finite polytopes

So the clean Mathlib route is **not** to invoke a finished polyhedral LP theorem.  The clean route is:

1. Add one geometric lemma in the repo: vertex displacement lies in the cone generated by outgoing edge directions.
2. Use the short, fully algebraic Mathlib-backed LP assembly below.

## Minimal extra lemma to prove in the repo

Use a concrete finite-cone membership predicate, rather than fighting the abstract `ConvexCone.hull` API.  This is ideal for downstream LP optimality because it immediately exposes coefficients.

For a finite edge-direction set `D : Finset E`:

```lean
x ∈ coneSpanFinset D
```

means exactly:

```lean
∃ a : E → ℝ,
  (∀ e ∈ D, 0 ≤ a e) ∧
  ∑ e in D, a e • e = x
```

The single missing geometric theorem should be stated in the repo’s polytope vocabulary as:

```lean
-- schematic, using the repo's actual vertex/edge/face fields
 theorem vertex_displacement_mem_edge_cone
    (P : ConvexTriangulatedPolytope) (v u : P.Vertex) :
    P.pos u - P.pos v ∈ coneSpanFinset (outgoingEdgeDirs P v)
```

This is exactly “tangent cone at a polytope vertex is generated by the outgoing edge rays.”

### Clean proof of the missing geometric lemma from the face data

Given the repo setup “oriented faces + outward normals + strict supporting halfspaces,” prove it in 3D as follows.

1. Define the incident-face H-cone at `v`:

```lean
Hcone v := { y : E3 | ∀ f ∈ incidentFaces v, ⟪normal f, y⟫ ≤ 0 }
```

with the sign chosen so the polytope is in `⟪normal f, x - pointOnFace f⟫ ≤ 0`.

2. Prove every polytope displacement lies in `Hcone v`:

```lean
x ∈ polytope → x - pos v ∈ Hcone v
```

because for every incident face `f`, `pos v` lies on the face, hence `⟪normal f, pos v - pointOnFace f⟫ = 0`, and `x` satisfies the supporting halfspace.

3. Prove the 3D local H=V cone lemma:

```lean
Hcone v = coneSpanFinset (outgoingEdgeDirs P v)
```

The cleanest 3D proof is via the vertex link.  Intersect `Hcone v` with an affine plane transverse to the cone, e.g. `⟪axis, y⟫ = 1` for an inward axis in the cone.  The section is a convex polygon.  Its vertices are the normalized outgoing edge rays.  Then `Finset.mem_convexHull'` gives a convex-combination certificate in the section; multiplying by the positive height recovers a conic-combination certificate in the cone.

This avoids formalizing full Minkowski-Weyl.  It only needs the link polygon convexity already present in Route B and the finite convex-hull/barycentric Mathlib API.

## Complete Mathlib-backed LP assembly after the geometric lemma

The following code is the reusable theorem stack.  It proves all LP bookkeeping after the single geometric input `hT : ∀ u, pos u - pos v ∈ coneSpanFinset D`.

```lean
import Mathlib

noncomputable section

open scoped BigOperators
open Set

namespace ProofsInTheBook.Ch13VertexLPRoute

variable {E : Type*}

/-- Finite conic span with exposed coefficients.  This is intentionally simpler
than `ConvexCone.hull` for the final LP step. -/
def coneSpanFinset [AddCommMonoid E] [Module ℝ E] (D : Finset E) : Set E :=
  {x | ∃ a : E → ℝ,
      (∀ e ∈ D, 0 ≤ a e) ∧
      ∑ e in D, a e • e = x}

section Linear

variable [AddCommGroup E] [Module ℝ E]

/-- A linear functional nonnegative on every generator is nonnegative on the
finite conic span of those generators. -/
theorem LinearMap.nonneg_on_coneSpanFinset
    {D : Finset E} (ℓ : E →ₗ[ℝ] ℝ) {x : E}
    (hx : x ∈ coneSpanFinset D)
    (hD : ∀ e ∈ D, 0 ≤ ℓ e) :
    0 ≤ ℓ x := by
  rcases hx with ⟨a, ha_nonneg, hxsum⟩
  have hsum_nonneg : 0 ≤ ∑ e in D, a e * ℓ e := by
    exact Finset.sum_nonneg (fun e he =>
      mul_nonneg (ha_nonneg e he) (hD e he))
  have hmap : ℓ (∑ e in D, a e • e) = ∑ e in D, a e * ℓ e := by
    simp [map_sum, map_smul]
  rwa [← hmap, hxsum] at hsum_nonneg

/-- Vertex-level LP optimality on the finite vertex set.  The only geometric input
is that every vertex displacement from `v` lies in the edge cone `D`. -/
theorem vertex_min_on_vertices_of_edgeCone
    {ι : Type*} [Fintype ι]
    (pos : ι → E) (D : Finset E) (v : ι) (ℓ : E →ₗ[ℝ] ℝ)
    (hT : ∀ u : ι, pos u - pos v ∈ coneSpanFinset D)
    (hD : ∀ e ∈ D, 0 ≤ ℓ e) :
    ∀ u : ι, ℓ (pos v) ≤ ℓ (pos u) := by
  intro u
  have hnonneg : 0 ≤ ℓ (pos u - pos v) :=
    LinearMap.nonneg_on_coneSpanFinset ℓ (hT u) hD
  have hdiff : 0 ≤ ℓ (pos u) - ℓ (pos v) := by
    simpa using hnonneg
  exact sub_nonneg.mp hdiff

/-- If a linear functional is bounded below by its value at `v` on every point of a
finite set `S`, then it is bounded below by that value on `convexHull ℝ S`.

This is the useful “linear functions on a finite convex hull are controlled by the
vertices” lemma.  It is just `Finset.mem_convexHull'` plus `Finset.sum_le_sum`. -/
theorem linear_ge_on_convexHull_of_ge_on_finset
    (S : Finset E) (ℓ : E →ₗ[ℝ] ℝ) (v : E)
    (hS : ∀ y ∈ S, ℓ v ≤ ℓ y) :
    ∀ x ∈ convexHull ℝ (S : Set E), ℓ v ≤ ℓ x := by
  classical
  intro x hx
  rcases (Finset.mem_convexHull' (R := ℝ) (s := S) (x := x)).mp hx with
    ⟨w, hw_nonneg, hw_sum, hxsum⟩
  have hmap : ℓ x = ∑ y in S, w y * ℓ y := by
    rw [← hxsum]
    simp [map_sum, map_smul]
  have hweighted : ∑ y in S, w y * ℓ v ≤ ∑ y in S, w y * ℓ y := by
    exact Finset.sum_le_sum (fun y hy =>
      mul_le_mul_of_nonneg_left (hS y hy) (hw_nonneg y hy))
  have hleft : ∑ y in S, w y * ℓ v = ℓ v := by
    rw [← Finset.sum_mul, hw_sum, one_mul]
  linarith

/-- Global polytope optimality for a finite vertex set.  Here the polytope is
`convexHull ℝ (Set.range pos)`. -/
theorem vertex_min_on_convexHull_from_edgeCone
    {ι : Type*} [Fintype ι] [DecidableEq E]
    (pos : ι → E) (D : Finset E) (v : ι) (ℓ : E →ₗ[ℝ] ℝ)
    (hT : ∀ u : ι, pos u - pos v ∈ coneSpanFinset D)
    (hD : ∀ e ∈ D, 0 ≤ ℓ e) :
    ∀ x ∈ convexHull ℝ (Set.range pos), ℓ (pos v) ≤ ℓ x := by
  classical
  let S : Finset E := Finset.univ.image pos
  have hrange : Set.range pos = (S : Set E) := by
    ext x
    simp [S]
  have hVert : ∀ y ∈ S, ℓ (pos v) ≤ ℓ y := by
    intro y hy
    rcases Finset.mem_image.mp hy with ⟨u, _hu, rfl⟩
    exact vertex_min_on_vertices_of_edgeCone pos D v ℓ hT hD u
  intro x hx
  rw [hrange] at hx
  exact linear_ge_on_convexHull_of_ge_on_finset S ℓ (pos v) hVert x hx

end Linear

section Inner

variable [NormedAddCommGroup E] [InnerProductSpace ℝ E]

/-- The inner-product linear functional `x ↦ ⟪g, x⟫`. -/
def innerLinear (g : E) : E →ₗ[ℝ] ℝ where
  toFun x := ⟪g, x⟫
  map_add' := by
    intro x y
    simp [inner_add_right]
  map_smul' := by
    intro r x
    simp [inner_smul_right]

@[simp] theorem innerLinear_apply (g x : E) : innerLinear g x = ⟪g, x⟫ := rfl

/-- Inner-product statement matching the Cauchy Route B use case. -/
theorem inner_vertex_min_on_convexHull_from_edgeCone
    {ι : Type*} [Fintype ι] [DecidableEq E]
    (pos : ι → E) (D : Finset E) (v : ι) (g : E)
    (hT : ∀ u : ι, pos u - pos v ∈ coneSpanFinset D)
    (hD : ∀ e ∈ D, 0 ≤ ⟪g, e⟫) :
    ∀ x ∈ convexHull ℝ (Set.range pos), ⟪g, pos v⟫ ≤ ⟪g, x⟫ := by
  simpa using
    (vertex_min_on_convexHull_from_edgeCone
      (pos := pos) (D := D) (v := v) (ℓ := innerLinear g) hT hD)

end Inner

end ProofsInTheBook.Ch13VertexLPRoute
```

## How to connect this to outgoing edges

Define the actual outgoing edge direction set in the repo’s graph data.  A typical finite definition is:

```lean
noncomputable def outgoingEdgeDirs
    {V E : Type*} [Fintype V] [DecidableEq E]
    [AddCommGroup E] [Module ℝ E]
    (pos : V → E) (Edge : V → V → Prop) [DecidableRel Edge] (v : V) : Finset E :=
  (Finset.univ.filter (fun w => Edge v w)).image (fun w => pos w - pos v)
```

Then instantiate the LP theorem with:

```lean
D := outgoingEdgeDirs pos Edge v
```

and prove:

```lean
hT : ∀ u, pos u - pos v ∈ coneSpanFinset D
hD : ∀ e ∈ D, 0 ≤ ⟪g, e⟫
```

The second is just unpacking membership in a `Finset.image` from the edge hypotheses.  The first is the geometric H=V/tangent-cone lemma described above.

## Why not use Mathlib Farkas directly?

The `ProperCone.hyperplane_separation_point` / `dual_dual_flip` route is theoretically valid, but it is not the shortest Lean path here.  It would require packaging the edge cone as a closed `ProperCone`, proving its dual is exactly the incident-face normal cone, then proving the normal cone is the polar of feasible vertex displacements.  That is at least as hard as proving the missing local H=V cone lemma.

For this project, the shortest route is:

```text
local geometric lemma:
  pos u - pos v ∈ cone(edge directions at v)

+ finite conic LP algebra:
  nonnegative on generators ⇒ nonnegative on every conic combo

+ finite convex-hull algebra:
  nonnegative on all vertices ⇒ nonnegative on convexHull(vertices)
```

Only the first line is geometry.  The last two lines are completely discharged by the code above.
